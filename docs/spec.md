# 로컬 가계부 — 설계 문서

## 1. 제품 성격

혼자 쓰는 개인용 모바일 PWA 가계부. 모든 지출을 기록하는 것이 목적이 아니라
**월급 분배 룰**과 **혜택·특가 소비 플랜**에 집중한다.

접근성(a11y), 테스트 커버리지, 린터, 다중 사용자 대응은 의도적으로 범위 밖에 둔다.
단 **데이터 유실 방지는 예외** — 사용자가 한 명이라 백업본이 사용자밖에 없고,
localStorage가 유일한 저장소이기 때문이다.

## 2. 저장소 구조

| localStorage 키 | 내용 |
| --- | --- |
| `LOCAL_LEDGER_DATA_V3` | 가계부 본체 (`AppState`: deals / salaryConfig / quickTags) |
| `LOCAL_LEDGER_BROKEN_<ts>_<rand>` | 읽지 못한 손상 데이터 스냅샷 |
| `LOCAL_LEDGER_PREIMPORT_<ts>_<rand>` | 복원·초기화로 교체되기 직전 스냅샷 |
| `LOCAL_LEDGER_AI_CONFIG` | AI 설정 (API 키, 모델명) — **가계부 본체와 분리** |

스냅샷은 최근 5개까지만 유지한다 (용량 폭주 방지).

## 3. 백업 안전 규칙

- 내보내기 파일에는 `app: "local-ledger"`, `schemaVersion`, `exportedAt` 헤더를 찍는다
- 복원은 **검증 → 사용자 확인 → 교체 직전 스냅샷 → 적용** 순서를 반드시 지킨다
- `deals` 배열과 `salaryConfig` 객체가 없으면 복원을 거부한다
  (엉뚱한 JSON이 기존 기록을 빈 상태로 덮어쓰는 사고를 막기 위함)
- **API 키는 백업 파일에 절대 포함하지 않는다.** 별도 localStorage 키에 두는 이유가 이것이다.
  백업 파일을 공유·업로드해도 키가 새지 않아야 한다

## 4. AI 연동 (Gemini)

### 4.1 결정 사항

| 항목 | 결정 |
| --- | --- |
| 제공자 | Google Gemini (Developer API) |
| 기본 모델 | `gemini-3.8-flash` (설정에서 변경 가능) |
| 엔드포인트 | `https://generativelanguage.googleapis.com/v1beta` |
| 인증 | `x-goog-api-key` 헤더 (쿼리 파라미터 `?key=` 대신 — URL·로그 유출 방지) |
| 기본 상태 | **꺼짐.** 키를 넣어야만 동작 |
| 요금제 | 무료 티어 전제. 한도 초과 시 안내 후 기존 정규식 파서로 폴백 |

CORS 확인 완료: preflight가 `x-goog-api-key`를 허용하고, GitHub Pages 오리진에
`Access-Control-Allow-Origin`이 응답된다. 별도 프록시 서버가 필요 없다.

### 4.2 키 취급 원칙

localStorage 저장은 서버가 없는 구조에서 유일한 선택지이며, **안전하다는 뜻은 아니다.**
전제와 완화책:

- **결제 미연결 무료 키를 쓴다.** 유출되어도 금전 피해가 없고 한도만 소모된다 (가장 중요)
- Google AI Studio에서 키에 API 제한(Generative Language API 한정)을 건다
- 입력란은 `type="password"`, 화면에는 마스킹된 형태로만 표시
- 언제든 삭제 가능
- **외부 스크립트를 앱에 들이지 않는다.** 현재 외부 스크립트가 0개라 XSS로 키가
  새어나갈 실질 경로가 없다. 이 조건이 깨지면 위 전제가 무너진다

### 4.3 기능 로드맵

1. **설정 화면 (키 관리)** — 현재 단계. 키 저장·삭제·연결 테스트.
   연결 테스트는 `GET /models`를 쓴다 (생성 쿼터를 소모하지 않고 키와 모델명을 동시에 검증)
2. **한 줄 자연어 입력을 AI로 교체** — 다음 단계.
   상대 날짜("다음주 화요일")·비율 할인("20%")처럼 정규식으로 불가능한 입력을 처리.
   전송 데이터는 입력 문장과 태그 목록뿐이며 **월급·저축 정보는 보내지 않는다.**
   실패·한도 초과 시 기존 정규식 파서로 폴백
3. **혜택 안내/영수증 스크린샷 인식** — 이후. 이미지는 토큰 소모가 커 한도를 빨리 쓴다
4. **이달 소비 리뷰** — 보류. 한 달치 데이터를 통째로 보내야 해서 프라이버시 대비 가치가 낮다

### 4.4 금지 사항

- **실시간 할인·특가 정보를 물어보는 기능은 만들지 않는다.**
  Gemini에는 실시간 행사 데이터가 없어 존재하지 않는 행사를 지어낸다.
  가계부에서 이는 단순 오답이 아니라 헛돈을 쓰게 만드는 오답이다
- **AI가 데이터를 직접 쓰지 않는다.** 항상 폼에 채워 넣고 사용자가 확인한 뒤 저장한다

### 4.5 문서 정합성

AI 기능을 켜면 데이터 일부가 Google로 전송되므로, README의
"Zero Server / 100% 로컬" 문구는 "AI 기능은 기본 꺼짐이며, 켰을 때 무엇이 전송되는지"를
명시하도록 수정해야 한다.
