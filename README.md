# 로컬 가계부 (Local Ledger)

할인·혜택 소비 플랜과 월급 분배 규칙을 위한 가벼운 모바일 PWA 가계부입니다.  
매일의 모든 잔돈을 빼곡히 기록하는 대신, **월급 분배 룰**과 **원하는 특가·할인 행사 소비 계획**에 집중하는 100% 브라우저 로컬 가계부입니다.

---

## 주요 특징

1. **초간편 모바일 입력 (Mobile-First UX)**
   - **바텀 시트 & 숫자 키패드 자동 매핑**: 한 손 조작에 최적화된 하단 시트 구조.
   - **자주 쓰는 행사 태그 칩**: `[네이버페이]`, `[배민]`, `[요기요]`, `[올영세일]`, `[통신사]`, `[카드할인]` 등 원터치 입력.
   - **한 줄 자연어 빠른 입력**: `15일 와퍼 6000 요기요 3000` 형태로 입력 시 날짜/품목/결제금액/할인액을 자동 파싱.

2. **달단위 혜택 소비 캘린더 & 타임라인**
   - 월간 달력에서 특정 날짜의 소비 플랜 및 행사 일정 확인.
   - **절약 효능감 시각화**: 이번 달 총 지출 예정액과 함께 총 할인 세이브 금액을 실시간 집계.
   - 실제 구매 완료 여부 체크박스 토글.

3. **월급 차감 룰 & 한계 소비 예산**
   - 월급을 만원 단위로 입력하고(예: 300), 차감할 항목(예: ISA 저금 100, 국민카드 40)을 만원 단위로 등록.
   - 차감 후 남은 금액(자유 예산)을 실시간으로 확인하여 전체적인 자금 틀 수립.
   - '소비'로 지정된 항목들의 합계가 '플랜' 탭의 **한계 소비 예산**으로 자동 연동되어 소비 한도 모니터링.

4. **보안 및 프라이버시 100% (Zero Server)**
   - 외부 서버나 데이터베이스 통신 없이 브라우저 `localStorage`에만 데이터 저장.
   - 언제든 클립보드 복사 또는 JSON 파일 다운로드로 백업 및 복원 가능.

5. **PWA (Progressive Web App)**
   - 모바일 브라우저에서 '홈 화면에 추가' 시 앱 아이콘과 함께 주소창 없는 전체화면 독립 앱 형태로 구동.
   - 오프라인 환경에서도 동작 지원.

---

## 스마트폰 홈 화면에 설치하는 법

- **iOS (Safari)**: 브라우저 접속 후 하단 중앙 [공유] 버튼 -> [홈 화면에 추가]
- **Android (Chrome / 삼성인터넷)**: 브라우저 상단 메뉴 -> [앱 설치] 또는 [홈 화면에 추가]

---

## 로컬 개발 및 빌드

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## GitHub Pages 배포

저장소 `main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`을 통해 자동으로 GitHub Pages(`https://<user>.github.io/local-ledger/`)에 빌드 및 배포됩니다.
